# Hermes-MCP 启动手册

> 本机基准：Windows 11 · conda 环境 `hermes-mcp` · Python 3.10。下面的命令都已实测。

---

## 1. 一次性准备

### 1.1 建 conda 环境并装依赖
```bash
conda create -n hermes-mcp python=3.10 -y
conda activate hermes-mcp
pip install -e ".[test]"      # 装包 + 测试依赖；也可改装 dialects 用
```
> 更多：见 `docs/conda-环境手册.md`。

### 1.2 配置环境变量
在环境里设定（或写 `.env` / 你的 shell profile）：
```bash
export HERMESMCP_DB_KEY='<加密key>'                 # 存库密码用；缺则不存密码
# export HERMESMCP_DB_CONFIG='/path/to/db_connections.db'   # 默认 <项目根>/db_connections.db，与配置页共享用同一路径
# export HERMESMCP_LLM_BASE_URL='<ark OpenAI端点>'   # ask 生成 SQL 才需要
# export HERMESMCP_LLM_API_KEY='<key>'              # ask 生成 SQL 才需要
# export MCP_TRANSPORT='http'                        # 仅 HTTP 调试用，默认 stdio
```
> 完整变量表见 `README.md`。key 是敏感项，别贴进对话/仓库。

### 1.3 建样例库并注册连接
```bash
python scripts/make_sample_db.py
# -> 生成 data/sample.db，并在 db_connections.db 注册名为 sample 的连接
```

## 2. 跑测试
```bash
pytest                 # 39 个用例（security / query_runner / connections / store / introspection / sqlgen / api）
```

---

## 3. 启动方式 A：stdio（MCP 标准姿势，给 Hermes 打包用）

MCP 客户端（Hermes）通过子进程拉起本服务，走 stdin/stdout 管道：
```bash
python -m hermes_mcp.server
```
- 它一启动就等待 MCP 客户端（stdio）连接，**命令行看着像"没输出/挂住"是正常的**，等 `tools/list`。
- 验证 stdio 是否可用（会拉起服务端并真调工具，退出即结束）：
  ```bash
  python scripts/mcp_probe_client.py
  ```

**Hermes 侧登记**（占位，最终以真 Hermes 的 MCP 配置说明为准）：
```
command : python
args    : ["-m", "hermes_mcp.server"]
```

---

## 4. 启动方式 B：HTTP（跨机 / 远程调试用，备选传输）

MCP 客户端经网络调本服务的 `streamable-http` 端点。适合 Hermes 不能同机拉起、或你自己想用 HTTP 调试时。
```bash
python scripts/run_http.py                       # 默认 127.0.0.1:9123
HERMESMCP_HOST=0.0.0.0 HERMESMCP_PORT=9123 python scripts/run_http.py   # 暴露给别的机器
```
验证 HTTP 是否通（连 `http://127.0.0.1:9123/mcp` 并真调工具）：
```bash
python scripts/http_probe_client.py              # 默认 http://127.0.0.1:9123/mcp
# 或指定地址： python scripts/http_probe_client.py http://<host>:<port>/mcp
```
> `run_http.py` 是后台进程；用完要 `Ctrl+C` 或在任务里停掉。端口冲突可改 `HERMESMCP_PORT`。

## 5. 联调验收探针
对共享的 `db_connections.db` 做客观验收（配置页同事也能跑同一个）：
```bash
python scripts/verify_contract.py --key "$HERMESMCP_DB_KEY"               # 只查+解密
python scripts/verify_contract.py --key "$HERMESMCP_DB_KEY" --test        # 外加真连 SELECT 1
python scripts/verify_contract.py --key "$HERMESMCP_DB_KEY" --connection <名字> --test
```
> `--test` 需要对应方言 driver（mysql→pymysql 等）。只用非生产只读账号。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `UnicodeEncodeError: gbk codec` | Windows 控制台编码：`PYTHONIOENCODING=utf-8 python ...` |
| `pwd: command not found` / 中文路径脚本 | 用 conda 环境的 python 绝对路径；脚本内中文输出用 ASCII |
| `ModuleNotFoundError: mcp.server.fastmcp` | 装的是 mcp **2.x**，用 `MCPServer`（本项目已适配），别西红柿回 1.x |
| `decrypt: FAIL` | `HERMESMCP_DB_KEY` 不一致 / 缺失 |
| `connect: FAIL (ModuleNotFoundError)` | 没装对应 driver，`pip install pymysql` 等 |
| 端口被占 | 改 `HERMESMCP_PORT` |
| `ask` 报 ConfigError | 没设 `HERMESMCP_LLM_BASE_URL/API_KEY`；`ask` 生成 SQL 需要 |
| 连数据库锁住 | 共享 SQLite 开 WAL；真库用只读账号 |

## 7. 启动顺序速查（调试整链路）
```
conda activate hermes-mcp
export HERMESMCP_DB_KEY=...
python scripts/make_sample_db.py            # 1. 样例库 + 注册
pytest                                     # 2. 测试
python scripts/mcp_probe_client.py          # 3. stdio 验证
python scripts/run_http.py                  # 4. HTTP 起服务（另开终端）
python scripts/http_probe_client.py         # 5. HTTP 验证
python scripts/verify_contract.py --key "$HERMESMCP_DB_KEY" --test   # 6. 联调探针
```
